# Demo Recording Pre-Flight Checklist

Before hitting record for the final SnapSight demonstration, strictly verify the following items to ensure a polished, professional, and privacy-safe video.

## 1. Environment Preparation
- [ ] Clean Windows Desktop (hide personal icons, files, and folders).
- [ ] Close all unrelated background applications.
- [ ] Turn on Windows "Do Not Disturb" (Focus Assist) to hide private notifications.
- [ ] Ensure no API keys, tokens, or passwords are visible in any open text editors or terminals.
- [ ] Close any private browser tabs.

## 2. SnapSight Readiness
- [ ] Verify you are launching the packaged executable (`dist/SnapSight/SnapSight.exe`), not running from the IDE.
- [ ] Confirm the `models/` directory is correctly positioned next to the executable.
- [ ] Ensure the 2.4 GB `Phi-3.5-mini-instruct-Q4_K_M.gguf` file exists in the `models/` folder.
- [ ] Open the application once before recording to cache the UI elements and avoid first-run stutters.
- [ ] Resize the SnapSight window to a comfortable 16:9 aspect ratio or cleanly fit the recording frame.

## 3. Demo Target Material
- [ ] Prepare a clean, non-controversial, and non-private target for screen capture (e.g., a Wikipedia page, a standard code snippet, or a public tech blog).
- [ ] Test the region selection on the target beforehand.

## 4. Recording Setup
- [ ] Verify screen recording software is capturing the correct display at 1080p or higher.
- [ ] Verify the microphone is selecting the correct audio input device.
- [ ] Do a 10-second test recording and listen to the audio playback for background noise or echo.

## 5. Security & Privacy Final Check
- [ ] Confirm no personal information will be caught in the region selection.
- [ ] Confirm no terminal windows are visible (unless intentionally demonstrating the benchmark scripts).
